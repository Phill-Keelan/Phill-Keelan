### 🔭 Current Projects
<p>Motivating Mike: This app is a fun and motivating task management tool that encourages users to complete their to-do list by engaging with anavatar. Users can select an avatar, which acts as their virtual companion or guide throughout their productivity journey. The app transforms task completion into an interactive experience, making everyday chores and goals more engaging and rewarding.
